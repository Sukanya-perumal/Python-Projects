Blog Website

A dynamic web application built using Python and Flask, utilizing Flask-SQLAlchemy for database management and object-relational mapping.

Features
* User Authentication: Secure user registration, login, and session handling.
* CRUD Operations: Users can create, read, update, and delete blog posts dynamically.
* Relational Database: Structured data models linking users to their respective blog posts.
* Responsive Design: Clean and accessible user interface for all device sizes.

Technologies Used
* Python
* Flask (Web framework)
* Flask-SQLAlchemy (Database ORM)
* HTML5 / CSS3 / Bootstrap (Frontend styling)
