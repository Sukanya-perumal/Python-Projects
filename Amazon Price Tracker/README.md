Amazon Price Tracker

An automation script developed to monitor product prices on Amazon and trigger real-time email notifications when prices drop.

Features

Web Scraping: Extracts live product pricing data directly from Amazon.
Price Monitoring: Tracks budget changes dynamically.
Instant Alerts: Sends real-time email notifications to your inbox when a price drop occurs.

Technologies Used
- Python
- Beautiful Soup 4(Web scraping and HTML parsing)
- Requests (Handling HTTP network requests)
- SMTPLIB (Python's built-in email service protocol)
